## A. 引用与页面上下文(本轮重点)

| # | 步骤 | 期望 |
|---|---|---|
| A1 | 停在网页 B → 新建对话 | 引用栏**自动**出现 B 的芯片(无需点击页面) |
| A2 | 正常网页之间切 tab(B→C→B) | 引用**逐个跟随**;切回 B 恢复 B 的引用集,不回退到别的页面 |
| A3 | 旧对话(引用 A)→ 新建对话 → 切回旧对话 | 新对话引用当前页;旧对话显示它自己的 A |
| A4 | 引用 A+B 的对话 → 切到新标签页(chrome://newtab) | 引用栏**空**(不留上一页芯片);该 tab 导航到真实网站后自动入住 |
| A5 | 删除最后一个引用芯片 → 发一条消息 → 切 tab | 本会话保持"已关闭引用"(发送不得把它复位);**新对话仍自动引用当前页** |
| A6 | 关闭引用的会话 → 切 tab / 反复切会话 | 该会话不被写回引用;其它会话不受影响 |
| A7 | 两个带不同引用的旧会话互切 → 再切 tab | 各自引用不串 |
| A8 | 点框选后**立刻**切到另一个会话 → 完成框选 | 元素与页面引用落回**发起框选的那个会话** |
| A9 | 某消息引用过的页面,该 tab 之后导航到别的网站 | 旧消息里的 chip 图标仍是**原站点**(不跟随导航变成新站点) |

## B. 页面读取(v2)

| # | 步骤 | 期望 |

## H. 技能(Skills)

| # | 步骤 | 期望 |
|---|---|---|
| H1 | 新对话输入 `/skill:` | 菜单列出三个内置技能(含描述);选中后正文以「技能 X」徽章折叠在气泡里,可展开/复制 |
| H2 | 说「帮我写一个技能:把选中文字翻译成英文」 | 模型载入 `skill-creator` → 起草 SKILL.md → 走 `save_skill`(弹确认卡,且**永不进 grant**)→ 设置页技能列表出现它 |
| H3 | 设置页「技能」视图:停用某技能 / 对内置技能点编辑与删除 | **停用 = 完全关闭**:既不进模型目录,`/skill:name` 也不会执行它(卡片上有说明)。想表达“模型不自动调用、但允许手动唤起”是另一种状态「仅手动」,两者别混;内置技能可停用,但编辑/删除置灰 + tooltip 解释 |
| H4 | 「从 GitHub 安装」贴一个 raw SKILL.md 链接 | **先预览**(名称/描述/正文摘要/解析告警)再确认;私有/内网地址被拒;缺 description 的文件被拒并说明原因 |
| H5 | 会话里先 `/skill:x` 载入一个技能,再触发压缩(`/compact` 或等自动压缩) | **该技能正文不被摘要扫走**(仍能在上下文里生效) |
