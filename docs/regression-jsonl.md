# JSONL 迁移与并发重构回归清单

> 决策 36（pi Agent 会话运行时）+ JSONL 存储迁移的浏览器回归清单。
> 每项标注：✅ 通过 / ❌ 异常（附控制台错误或工具注记原文）。

## A. 存储迁移（首次启动，只做一次）

- [ ] **A1** `chrome://extensions` 刷新扩展 → 重开侧边栏：旧会话自动迁移，列表完整
- [ ] **A2** 抽查 2-3 个旧会话：消息数/标题/引用标签页/压缩标记/草稿逐一在
- [ ] **A3** 刷新页面再次重启扩展 → 会话不翻倍（迁移幂等）

## B. 发送与队列（并发隔离）

- [ ] **B1** 会话 A 发长任务（"读取当前网页并详细总结"）→ 流式正常
- [ ] **B2** 流式中**切到会话 B** → B 视图干净（无 A 的流式气泡/停止按钮/工具卡）
- [ ] **B3** 在 B 发消息 → **B 立即开始执行**（不等 A，不入队）
- [ ] **B4** A 仍在流式时，在 **A 里再发一条** → 入队（队列条出现），A 完成后自动执行
- [ ] **B5** 队列条上**逐条删除**（X）→ 被删消息不再发送（验证原生队列移除生效）
- [ ] **B6** 停止按钮 → 中止当前轮 + 队列清空（队列条消失）

## C. 动作（CDP 可信输入）

- [ ] **C3** 点赞/计数按钮 → 计数只 **+1**（不双击）
- [ ] **C4** 被弹窗遮挡的按钮 → 降级注记（不点到遮挡物）
