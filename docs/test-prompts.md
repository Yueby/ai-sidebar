## 1. H3-A — 尾读长页（本轮刚修的失败点，优先测）

## 2. H3-B — offset 续读

> 这篇很长，请完整读完:先读一次；如果结果被截断，就按它给出的提示继续读，直到读到文末标记为止，然后把标记告诉我

**期望**:第一次结果末尾出现 `To read the rest, call read_page ... offset: N`，模型按该 offset 续读并报出 `ZEBRA-7391`。
**失败特征**:说"读不到后半段"；或反复读同一段（offset 没前进）。

## 3. H2 — 前端渲染页自动重试（用 `?delay=8000`）

先打开 `http://localhost:8789/?delay=8000`（正文 **8 秒后**才注入 = 前端渲染页），**趁它还没渲染完**发:

> 读取当前页面正文

**期望**:读到内容；若走了自动重试，回答前后会出现一行 `first extraction came back nearly empty`。
**说明**:默认 1.2s 版本人手动发提示词时正文早已就位，**测不到重试**，必须用 `?delay=`。
