使用说明

1. 本目录起本地服务：npx http-server fixtures/page-actions -p 8788（或 python -m http.server 8788）。
2. 浏览器打开 http://localhost:8788/，侧边栏引用该标签页。
3. 按上面各节的示例指令逐项驱动 agent，对照每节的 result 区域判定通过/失败。
4. 每次操作都会追加日志（含时间戳），方便核对 agent 声称的动作与页面真实反应是否一致。

这是一个固定定位的遮挡层（模拟弹窗/cookie 条）。它盖住了上方"被遮挡的按钮"。
